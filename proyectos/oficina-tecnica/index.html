Sistema de Gestión de Oficina Técnica

Aplicación web local creada para reunir en un solo lugar el registro de actividades, intervenciones, pendientes e información de infraestructura. Busca facilitar las consultas y mantener la continuidad del trabajo entre los integrantes de una oficina técnica.

01 · Necesidad detectada

¿Qué problema busca resolver?

La información de una oficina técnica puede quedar distribuida entre planillas, documentos y registros separados. El proyecto nació de la necesidad de centralizar las tareas diarias, las intervenciones realizadas, los asuntos pendientes y los datos de infraestructura para poder consultarlos con mayor facilidad.

La aplicación se diseñó como una herramienta de uso local, en un equipo dedicado, con una base de datos almacenada en ese mismo entorno.

02 · Funcionalidades

Qué permite hacer

Registro de actividades

Cargar varias tareas por día, consultar registros y organizar la información por fecha y sector.

Intervenciones y pendientes

Dejar asentadas las intervenciones realizadas y mantener visibles los asuntos que todavía requieren seguimiento.

Inventario e infraestructura

Registrar líneas telefónicas y datos técnicos asociados, como bloque, gateway, equipo, puerto, tablero y par de red.

Historial de información

Conservar referencias de cambios y ubicaciones de líneas para facilitar la consulta de antecedentes.

Usuarios y permisos

Acceso mediante usuarios y contraseñas, con permisos según el perfil y registro de operaciones relevantes.

Parte diario

Preparar un informe de las actividades para facilitar el traspaso de información entre relevos.

Exportación a Excel

Generar un archivo Excel con hojas separadas para actividades, intervenciones y pendientes.

Uso local

La aplicación se ejecuta en la computadora donde está instalada y guarda la información en una base de datos local.

03 · Herramientas

Tecnologías explicadas

Python

Lenguaje de programación utilizado para desarrollar la lógica de la aplicación: registrar datos, procesar información y ejecutar las funciones del sistema.

SQLite

Base de datos liviana que guarda los registros en un archivo local, sin necesitar instalar un servidor de base de datos separado.

HTML y CSS

HTML organiza los elementos que aparecen en pantalla; CSS define su presentación visual, colores, tamaños y distribución.

openpyxl

Librería de Python utilizada para crear archivos de Excel (.xlsx) con los datos exportados por la aplicación.

Seguridad de acceso

El sistema incorpora contraseñas almacenadas mediante hash PBKDF2, sesiones de usuario y controles de acceso. Esto aporta medidas básicas de protección, pero no equivale a una auditoría de seguridad independiente.

04 · Estado real

Alcance y aspectos pendientes

Prototipo funcional

Se desarrolló una aplicación local con registro de información, administración de datos, control de acceso, generación de parte diario y exportación a Excel.

La exportación a Excel está implementada. El envío automático mediante Gmail no se considera operativo: durante las pruebas apareció un error de autenticación SMTP. Por ese motivo, el procedimiento previsto es descargar el archivo y enviarlo manualmente como adjunto desde el correo.

Prototipo funcional · En evolución
Privacidad de la demostración

Esta descripción es general. Una demostración pública debe utilizar datos ficticios y recursos gráficos genéricos. No se publican nombres de usuarios, contraseñas, registros reales, datos de infraestructura ni información interna de la institución.

05 · Aprendizajes

Qué representa este proyecto

El desarrollo permitió transformar una necesidad concreta de organización del trabajo en una herramienta de software. También implicó practicar programación, almacenamiento de datos, diseño de interfaces, gestión de usuarios, generación de informes y resolución de errores durante las pruebas.

El proyecto continúa siendo una aplicación local en evolución; no se presenta como un producto comercial ni como un sistema desplegado para uso general.
